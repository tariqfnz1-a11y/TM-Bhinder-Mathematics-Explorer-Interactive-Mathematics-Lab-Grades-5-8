TM Bhinder · Privacy, Accessibility & Terms

Privacy

This learning application does not request student accounts or intentionally collect, transmit or retain answers entered into its activities. Scores and reflections exist only in the page's memory and disappear when the tab is closed or reloaded. There are no timers, analytics, cookies or advertising.

The site is hosted on GitHub Pages, which may process technical connection information (such as IP address and request logs) under its own privacy policies. This is infrastructure-level processing by the host, not collection by the application.

Accessibility

Number Explorer is built toward WCAG 2.2 AA: keyboard-operable tabs and sliders, visible focus indicators, live-region feedback, text descriptions for visual models, sufficient colour contrast, and no time limits.

Status: not yet certified. Keyboard and automated checks are complete; full screen-reader testing (e.g., NVDA), 200%/400% zoom and mobile testing are pending. Please report any barrier via the Maths Lab Hub.
